## Unresolved provider contracts

WANotifier's documented Messaging API success response is only
`{error:false,message:"Message sent successfully."}` without a wamid. Confirm a
real receipt or supported lookup with WANotifier before enabling operator sends.
The transport accepts an actual `messages[0].id` wamid if present, but does not
assume it exists; missing receipt is ambiguous after the single call.

The documented webhook event list covers message.received/contact.created/
contact.updated, not outgoing delivered/read events. Delivery reports cannot be
claimed synchronized until the provider supplies an appropriate status source.

Templates require approved templates in this new WABA and a separately saved
Transactional/Integration/API Notification for each mapped template. Notification
URLs and JSON keys are generated by WANotifier; do not invent them or send job
alerts via the session-only Messaging API. Campaign-worker integration remains
pending those verified notification contracts and receipt/status handling.
